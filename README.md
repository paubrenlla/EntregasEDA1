# Data Structures & Algorithms Foundations (EDA 1)

> **Academic Project** | Data Structures and Algorithms 1  
> **Universidad ORT Uruguay** | Semester: March 2024

## Context
This project focuses on the manual implementation of abstract data types (ADTs) and fundamental algorithms using **C++**. 

**Note on Framework:** The testing infrastructure and class skeletons were provided by the teaching team at **Universidad ORT Uruguay**. My contribution consisted of developing the full logic and implementation for each of the required data structures and their associated methods.

## Implemented Structures
The following data structures were built from scratch (using pointers and manual memory management):
* **Linear Structures:** * Singly and Doubly Linked Lists.
    * Stacks (LIFO) and Queues (FIFO).
* **Non-Linear Structures:**
    * Binary Search Trees (BST).
    * AVL Trees (Self-balancing logic).
* **Algorithms:** Recursive and iterative traversals, search, and sorting within the structures.

## Key Learning Outcomes
* **Memory Management:** Professional handling of pointers, dynamic allocation, and deallocation to prevent memory leaks.
* **Algorithm Efficiency:** Focus on Big O notation (Time and Space complexity).
* **Unit Testing:** Passing a rigorous suite of automated tests provided within the framework to ensure edge-case reliability.

## Project Structure
* `Implementacion/`: Core logic for each ADT.
* `Interfaces/`: Definition of the contracts and structure skeletons.
* `Tests/`: Validation scripts for the implemented logic.

## Technical Stack
* **Language:** C/C++
* **Concepts:** OOP, Templates, Memory Management, Recursion.
